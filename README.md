MuseArte es una página web que te permite explorar un museo virtual de arte moderno. En ella podrás descubrir una colección de 16 obras destacadas, que incluyen tanto a artistas establecidos como a nuevos talentos. La navegación es fluida y te permite conocer más sobre el proyecto en la sección "Acerca".

Construida con Node.js, Express y Pug, la página ofrece una experiencia clara y visualmente atractiva. También cuenta con un middleware que registra las visitas al servidor, proporcionando información sobre la interacción con el sitio.

MuseArte está desplegado en Vercel, lo que asegura que la página esté disponible y cargue rápidamente desde cualquier lugar.
